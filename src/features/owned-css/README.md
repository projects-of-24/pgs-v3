## Rules for every pass

- Copy verbatim, same order. Only allowed change: relative `url(../…)` → absolute `/assets/…`.
- Rules with no selector match in the site → `split/parked/` with a comment pointing back to the source line; the live file gets a comment where they were cut.
- Verify: postcss rule/selector/declaration/`!important` counts (live + parked = source) and normalized diff.

## Do not

- Import `split/` files into the lab barrel or any live route until OWN-LINK (loading them after Hostinger would reorder the cascade).
- Edit Hostinger `style.css` / `responsive.css`.
- Use `/preview/countriesuk-owned-css` (redirects here).
